# $SHELLTACIO

Мем-коин лендинг про фисташку, которая треснула криво, осталась в баре в общей
миске закусок и так и не была выбрана. Тема — доска объявлений "потеряшка"
(corkboard / lost & found), в духе флаера "have you seen me?".

Чистый HTML/CSS/JS, без сборки — просто открыть `index.html` или задеплоить
папку как статический сайт (Vercel: Import Project → без build command).

## Что настроить при запуске токена

В `script.js`, объект `CONFIG` в начале файла:

- `CA` — адрес контракта. Пока пусто → везде плейсхолдер "COMING SOON — NOT
  MINTED YET", кнопка Buy неактивна, статы в разделе "Sightings" не грузятся.
  Как только впишешь адрес — статы (цена/капа/ликвидность/24ч) сами подтянутся
  с DexScreener, кнопки copy заработают.
- `CHART_URL` — ссылка на DexScreener/чарт.
- `BUY_URL` — ссылка на покупку (pump.fun / jupiter).
- `X_URL`, `TELEGRAM_URL` — соцсети.

## Фичи

- Скорлупа "щёлкает": обе половинки скорлупы — отдельные PNG-слои
  (`assets/ear-left.png`, `assets/ear-right.png`), наложенные поверх базовой
  картинки (`assets/hero-base.jpg`, там скорлупа стёрта под фон). Они
  покачиваются в холостую (CSS keyframes с разной задержкой на каждое ухо) и
  резко "щёлкают" сильнее при клике/тапе по персонажу — плюс вспышка и
  счётчик "poked N times".
- Мухи реально летают по всей странице — слой `#fliesLayer` (`position:
  fixed`), JS анимирует 14 (8 на мобильных) SVG-мух с взмахом крыльев через
  CSS keyframes, они блуждают по всей странице и периодически летят к голове
  персонажа.
- Звук выключен по умолчанию — кнопка 🔇/🔊 в шапке включает лёгкое жужжание
  (Web Audio, 3 осциллятора) + звук "щелчка" при поке скорлупы.
- Копирование CA в один клик (шапка и футер).

## Структура

```
index.html
style.css
script.js
assets/
  hero-base.jpg   — персонаж + куча скорлупы, БЕЗ верхних "ушей" скорлупы (стёрты под фон)
  ear-left.png     — левая половинка скорлупы (прозрачный низ), накладывается поверх hero-base
  ear-right.png    — правая половинка скорлупы
  og-image.jpg     — превью для соцсетей / favicon
```

Если нужно поменять картинку персонажа — придётся заново вырезать половинки
скорлупы тем же приёмом (bounding box + альфа-градиент по низу), просто
заменить файлы не получится, геометрия завязана на конкретный кадр.
