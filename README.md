# $SHELLTACIO

Мем-коин лендинг про фисташку, которая треснула криво, осталась в баре в общей
миске закусок и так и не была выбрана. Тема — доска объявлений "потеряшка"
(corkboard / lost & found), в духе флаера "have you seen me?". Герой — full
screen: персонаж без рамки/карточки плавает прямо на текстуре пробковой доски,
вокруг разбросаны десятки фисташковых скорлупок и мух на весь экран.

Чистый HTML/CSS/JS, без сборки — просто открыть `index.html` или задеплоить
папку как статический сайт (Vercel: Import Project → без build command).

## Что настроить при запуске токена

В `script.js`, объект `CONFIG` в начале файла:

- `CA` — адрес контракта. Пока пусто → везде плейсхолдер "COMING SOON — NOT
  MINTED YET", кнопка Buy неактивна, статы в разделе "Sightings" не грузятся.
  Как только впишешь адрес — статы (цена/капа/ликвидность/24ч) сами подтянутся
  с DexScreener, кнопки copy заработают.
- `CHART_URL` — ссылка на DexScreener/чарт.
- `BUY_URL` — ссылка на покупку (pump.fun / jupiter).
- `X_URL`, `TELEGRAM_URL` — соцсети.

## Фичи

- **Герой на весь экран, без рамки.** `assets/hero-base.png` — не JPG с плоским
  фоном, а PNG с вырезанным по хромакею фоном (альфа-канал), поэтому персонаж
  с кучей скорлупы floats прямо на текстуре пробковой доски без видимого
  прямоугольника вокруг. Половинки скорлупы (`assets/ear-left.png`,
  `assets/ear-right.png`) — тем же способом, только ещё с fade-маской по низу
  (там, где они "крепятся" к телу).
- **Много скорлупы и мух по всему экрану.** `.shell-scatter` в hero — 17
  декоративных скорлупок (`assets/scatter-1.png` … `scatter-7.png`, вырезаны
  из той же исходной картинки с эллиптическим fade по краям), раскиданы по
  всему вьюпорту с лёгким покачиванием (CSS). Мух стало заметно больше — 30 на
  десктопе / 16 на мобильных (было 14/8), с разбросом по размеру (часть
  крупнее/ближе к камере) для ощущения плотного роя.
- **Скорлупа двигается на пружинной физике, не на CSS keyframes.** В покое
  каждое ухо гоняется демпфированной пружиной (JS, `requestAnimationFrame`) за
  плавно дрейфующей целью — суммой из нескольких синусоид разной частоты и
  фазы на каждое ухо (никогда не синхронизируются, никогда не повторяется один
  в один), плюс редкие короткие "вспышки" учащённого дрожания. Клик/тап даёт
  пружине импульс скорости в разные стороны — она сама затухающе
  раскачивается и оседает, это выглядит гораздо естественнее фиксированного
  keyframe-анимации. Параметры — `EAR_STIFFNESS`/`EAR_DAMPING` в начале блока
  "shell ear physics" в `script.js`.
- Отклик на клик — не отдельный белый прямоугольник (он бы читался как рамка
  поверх безрамочного героя), а `filter: brightness()/saturate()` пульс прямо
  на вырезанных слоях (следует силуэту альфа-канала).
- Звук выключен по умолчанию — кнопка 🔇/🔊 в шапке включает лёгкое жужжание
  (Web Audio, 3 осциллятора) + звук "щелчка" при поке скорлупы.
- Копирование CA в один клик (шапка и футер).

## Структура

```
index.html
style.css
script.js
assets/
  hero-base.png    — персонаж + куча скорлупы, фон вырезан по хромакею (альфа), БЕЗ верхних "ушей" (стёрты)
  ear-left.png      — левая половинка скорлупы, фон вырезан + fade-маска по низу
  ear-right.png     — правая половинка скорлупы
  scatter-1..7.png  — декоративные скорлупки для фона hero (эллиптический fade по краям)
  og-image.jpg      — превью для соцсетей / favicon (тут фон намеренно НЕ вырезан — плоский фон нужен для соцкарточки)
```

Если нужно поменять картинку персонажа — придётся заново прогонять вырезку:
1. Хромакей фона (порог по дистанции цвета от фона, ~10–50, см. историю сессии
   в проекте) → прозрачный PNG всего кадра.
2. Из него вырезать половинки скорлупы (bounding box + альфа-градиент по низу)
   и декоративные скорлупки для scatter (bounding box + эллиптический fade).
3. На базовом слое "стереть" область под ушами той же маской, что и у overlay
   (не заливкой цветом фона — теперь там прозрачность, не плоский цвет).

Просто заменить файлы не получится — геометрия (проценты позиционирования
ушей в CSS) завязана на конкретный кадр.
